# 🎛️ m3uToStrm-gui

Графический конвертер плейлистов `.m3u` в `.strm`-файлы для удобной интеграции с медиаплеерами и медиацентрами (например, Kodi).

## 📦 Возможности

- Загрузка и парсинг `.m3u` плейлистов
- Автоматическое создание `.strm` файлов для каждого потока
- Удобный графический интерфейс на WinForms
